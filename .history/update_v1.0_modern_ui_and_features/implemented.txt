================================================================================
BASIC WEB BROWSER - COMPLETED IMPLEMENTATION SUMMARY
================================================================================

1. PROJECT OVERVIEW & TECH STACK
--------------------------------------------------------------------------------
- Application: Desktop Web Browser
- Language / Platform: Java 21 LTS
- Framework: JavaFX 21 (javafx-controls, javafx-web)
- Rendering Engine: WebKit (WebView & WebEngine)
- Build System: Maven (javafx-maven-plugin 0.0.8)
- UI Styling: CSS3 (src/main/resources/styles.css)


2. COMPLETED FEATURES & LOGIC
--------------------------------------------------------------------------------
* Navigation Controls:
  - Back Button (<-): Navigates backward in session history with boundary safe-guards.
  - Forward Button (->): Navigates forward in session history with boundary safe-guards.
  - Reload Button (↻): Reloads current webpage.
  - Go Button & Enter Key: Navigates to the URL entered in the address bar.
  - Auto-Protocol Prefix: Automatically prepends "https://" to URLs if omitted.

* Dynamic Synchronization:
  - Dynamic Address Bar: Automatically synchronizes when navigating internal links or redirects.
  - Dynamic Window Title: Window title bar updates in real time to match the document title.

* Visual Feedback:
  - Slim modern gradient progress bar (2.5px height) tied to WebEngine loading status.
  - Progress bar smoothly shows during page load and hides automatically when finished.

* Default Modern Start / Home Page:
  - Embedded HTML5/CSS3 dark-mode landing screen.
  - Responsive shortcut cards for Google, GitHub, Wikipedia, and Hacker News.
  - Glassmorphism UI styling, hover animations, and dark gradient background.

* Modern UI Design System (styles.css):
  - Pill-shaped address bar with blue focus glow.
  - Rounded action buttons with hover and pressed states.
  - Clean typography and native feel.
